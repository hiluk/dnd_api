# Предыстории и навыки

Дата: 2026-11-01. Затрагивает `dnd_api` и `dnd_app`. Продолжение
[генерации характеристик](2026-10-31-ability-generation-design.md).

## Цель

Персонаж 1 уровня получает предысторию и владение навыками по правилам «Книги игрока»:
от предыстории, расы и класса, плюс компетентность плута. Сервер проверяет выбор и считает
бонусы 18 навыков и пассивную внимательность.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Предыстории | 13 из «Книги игрока» + «Своя предыстория» (2 любых навыка); описания своими словами |
| Компетентность плута | Сразу, на 1 уровне: 2 навыка из тех, которыми персонаж владеет |
| Повтор навыка из разных источников | Нельзя выбрать уже полученный навык — мастер предлагает только новые |
| Инструменты, языки, снаряжение, умение предыстории | Только текстом, без механики |
| Старые персонажи | Удаляются миграцией |

## Сервер

### Данные

- `Skill` — 18 навыков (коды 1–18): Акробатика, Уход за животными, Магия, Атлетика, Обман,
  История, Проницательность, Запугивание, Анализ, Медицина, Природа, Внимательность,
  Выступление, Убеждение, Религия, Ловкость рук, Скрытность, Выживание. Характеристика
  каждого навыка задана в правилах.
- `Background` (таблица `backgrounds`): `Type`, `Name`, `Description`, `Skills` (`Skill[]`),
  `SkillChoices`, текстовые `Tools`, `Languages`, `Equipment`, `Feature`.
  «Своя предыстория»: `Skills = []`, `SkillChoices = 2`.
- `CharacterClass`: `SkillChoices`, `SkillOptions` (`Skill[]`), `ExpertiseChoices`
  (плут — 2, остальные — 0).
- `Race`: `Skills` (эльф — Внимательность, полуорк — Запугивание), `SkillChoices`
  (полуэльф — 2).
- `Character`: `Background`, `BackgroundSkills` (только для своей предыстории), `RaceSkills`,
  `ClassSkills`, `Expertise`.

### Правила

Проверка по шагам (ошибки — по полям `BackgroundSkills`, `RaceSkills`, `ClassSkills`,
`Expertise`):

1. Предыстория: фиксированные навыки; если `SkillChoices > 0` — ровно столько разных навыков.
2. Раса: фиксированные навыки; выбор — ровно `SkillChoices` разных навыков, которых ещё нет.
3. Класс: ровно `SkillChoices` разных навыков из `SkillOptions`, которых ещё нет.
4. Компетентность: ровно `ExpertiseChoices` разных навыков, которыми персонаж владеет.

Бонус навыка = модификатор характеристики + бонус мастерства × (2 — компетентность,
1 — владение, 0 — нет). Пассивная внимательность = 10 + бонус Внимательности.

### API

- `GET /backgrounds` — справочник, без авторизации.
- Черновик (`/characters/preview`, `/characters/create`): `background`, `backgroundSkills`,
  `raceSkills`, `classSkills`, `expertise`. В превью `background` можно не указывать: так мастер
  получает итог характеристик до шага навыков; навыки тогда не проверяются и считаются без
  владения. Для создания предыстория обязательна («Выберите предысторию»).
- Персонаж: те же поля. Лист: `skills` (`skill`, `ability`, `bonus`, `proficient`, `expertise`)
  и `passivePerception`.
- Справочники рас и классов получают новые поля.

## Клиент

Шаги мастера: … → бонусы расы → предыстория → навыки → итог.

- Предыстория — раскрывающийся список с описанием, навыками и текстовыми полями.
- Навыки — один экран с разделами, которые показываются при необходимости: навыки
  предыстории (своя предыстория), навыки расы (полуэльф), навыки класса, компетентность (плут).
  Сверху — уже полученные навыки с источником. Недоступные варианты заблокированы.
  Превью обновляется на лету.
- Лист персонажа: блок «Навыки» (по алфавиту, с характеристикой, бонусом, ● владение,
  ◆ компетентность) и «Пассивная внимательность».

## Тестирование

- Сервер, юнит-тесты правил: своя предыстория, выбор полуэльфа, повтор навыка, навык не из
  списка класса, компетентность без владения и у не-плута, бонусы плута с компетентностью,
  пассивная внимательность.
- Сервер, интеграционные: `/backgrounds`, создание с навыками, лист с навыками.
- Клиент: кубит выбора навыков, шаги мастера, разбор листа.
- Вручную: полуэльф-плут со своей предысторией и обычный персонаж.
